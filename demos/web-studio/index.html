Claude Code el cerebro que arma tus videos con tu licencia

  1. 1Detectar
    Buscando…
  2. 2Instalarmétodos oficiales

    Fuente: code.claude.com/docs/en/setup. En Windows se recomienda Git for Windows (si falta, Claude usa PowerShell). No hace falta ser administrador.

  3. 3Iniciar sesióncon la cuenta de Claude de tu empresa

    Se abrirá una ventana negra con Claude y luego el navegador: entra con tu cuenta, y cuando diga Login successful pulsa Enter, escribe /exit y cierra la ventana.

    Usar un token de larga duración (opcional)

    «Generar token» ejecuta claude setup-token; copia el token que imprime y pégalo aquí. Se guarda cifrado con Windows (DPAPI) en tu perfil (%APPDATA%\MNVideoStudio), nunca en la carpeta del proyecto, y la app se lo pasa a Claude como CLAUDE_CODE_OAUTH_TOKEN. Fuente: authentication.

  4. 4Probar conexión
    Hace una llamada mínima (unos cientos de tokens).
