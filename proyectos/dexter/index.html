En palabras simples

¿Qué es y para qué sirve?

¿Qué es un agente de IA?

Un LLM (modelo de lenguaje grande, la IA que entiende y genera texto) con herramientas: puede leer archivos, correr comandos y editar código, paso a paso, hasta cumplir una tarea. Es como un asistente que, además de contestar, actúa.

El problema

Cada sesión empieza desde cero: el agente olvida decisiones, convenciones y errores ya resueltos. Cada herramienta se configura distinto, y conectarle WhatsApp, la casa inteligente o una revisión de seguridad hay que hacerlo pieza por pieza.

La solución

Un «cerebro base» que se inyecta en la configuración de cada agente: un índice ligero de capacidades, skills que se cargan bajo demanda, memoria entre sesiones y un auditor que revisa todo código externo antes de correrlo.

Paso a paso

Cómo funciona

Se instala una vez; después crece con cada sesión.

Instala

Un instalador en Bash, PowerShell o una interfaz de terminal detecta qué agente usas y respalda tu configuración actual antes de tocar nada.

Inyecta

Agrega las instrucciones base y el índice de capacidades, copia las skills y configura los servidores MCP, los hooks (acciones automáticas en eventos del agente) y los permisos.

Carga bajo demanda

Cada paquete de skills se activa solo cuando la conversación menciona sus palabras clave; en contexto queda solo el índice, así se gastan menos tokens.

Recuerda y crece

Guarda decisiones, errores y descubrimientos en su memoria. Si falta una habilidad, la genera, la audita y la activa sin reiniciar.

Cómo está construido

Multi-agente

Claude Code, OpenCode, Codex, Cursor, Gemini CLI y VS Code: un mismo ecosistema en todos.

Una estrategia por agente

Cada agente guarda su configuración distinto, así que el instalador fusiona JSON, reemplaza archivos, escribe TOML o agrega al final según el caso, siempre con respaldo previo.

MCP (Model Context Protocol)

Un estándar abierto para conectar herramientas y datos a un agente. Dexter configura la memoria Engram y Context7 (documentación de librerías al día) como servidores MCP.

Memoria local (Engram)

SQLite con FTS5, la búsqueda de texto completo de SQLite. Guarda y recupera contexto entre sesiones, en tu equipo.

Python, Node.js y Go

Skills en Markdown con scripts de Python; servidores de WhatsApp y Telegram en Node.js (WhatsApp con la librería Baileys); instalador visual en Go con Bubbletea.

Open source y probado

Código abierto bajo Apache 2.0, en desarrollo activo, con pruebas de pytest para los scripts y de bats para el instalador.
