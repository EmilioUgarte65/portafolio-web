Automation & Integrations

Chat celebrations, without manual work.

Festo is an unattended Node.js service: it runs on its own, with nobody starting it. Every morning it checks the team directory, finds whose birthday it is and sends them a WhatsApp greeting with their name and a celebration card. If something fails, it retries at midday without sending duplicates.

In plain words

What is it and what is it for?

What is unattended automation?

A program that does a repetitive task on its own, at the set time, without anyone starting it, and keeps a record of what it did.

The problem

Greeting each team member depends on someone remembering, checking the list and sending the message. On a large team, someone always gets left out.

The solution

Festo reads the directory HR already maintains (an Excel sheet), finds today's birthdays and sends the message with the card, with nobody involved.

Step by step

A morning with Festo

Check

At 9:00 it reads the directory (name, mobile, birth date and role) and filters today's birthdays using the correct time zone.

Personalize

It builds the message with the person's name and the celebration card.

Send

It waits until WhatsApp is connected and sends the greetings one by one, pausing between sends.

Log and retry

Each send goes into a log. At midday it checks again and only messages whoever was missed.

What it does

An end-to-end automated flow

From the team list to the delivered message, with no manual steps.

Daily detection

A job scheduled first thing in the morning checks the directory and finds the dates that match today. It accepts Excel dates or DD/MM/YYYY, and phone numbers with or without country code.

Personalized card

The message carries the person's name and a celebration card.

Messaging dispatch

Connects to WhatsApp to deliver the message and the card on time.

No duplicates

Keeps track of who was already greeted today, so nobody gets the message twice.

Automatic retry

If WhatsApp was not connected in the morning, the midday check completes the pending sends.

Send log

Every send is stored in a JSONL file (one record per line), easy to review and audit.

Test mode

It can send everything to a test phone and run immediately, without waiting for 9:00.

Web panel for manual use

A React app to upload the Excel file, see upcoming birthdays, add people, preview the card with the name (drawn on canvas, the browser's drawing surface) and send messages by hand.

Linked with a QR code

It connects by scanning a QR code from WhatsApp, like WhatsApp Web. The session is saved and survives server restarts.

Under the hood

How it is built

Two Docker containers

One container for the WhatsApp server and one for the birthday bot. They share a data folder with the directory, template, session and log. Docker makes it run the same on any server.

WhatsApp server with Baileys

Baileys is a library that speaks the WhatsApp Web protocol. The server exposes a small REST API (a web interface for programs): status, QR code, send text and send image.

Node.js bot

Uses node-cron for fixed-time jobs (morning check and midday retry) with an explicit time zone, so it does not depend on the server clock.

Excel directory

Reads the sheet with the xlsx library, so HR keeps the list in the tool it already uses, without entering data into another system.

React + Vite panel

The manual web app shares the same WhatsApp server and draws the personalized card in the browser.

Personal data protected

The WhatsApp session and the directory are never committed to the repository: a new install simply scans the QR again.

A frictionless administrative process

Automation designed to free up administrative time and ensure no team celebration is missed.
