Chat celebrations, without manual work.

Festo is a background Node.js service that checks database records every morning, identifies employees with birthdays, dynamically generates a personalized card, and dispatches it via chat on schedule. No reminders or manual tasks required from the team.

Festo

End-to-end automated workflow

Daily database detection

A scheduled morning process queries employee records, matching the current date with birthdays.

Dynamic card rendering

Renders a personalized greeting card image at runtime, overlaying the employee's name onto the celebration template.

Chat API delivery

Connects to the messaging API (WhatsApp / Chat) to deliver the card and message promptly.

A frictionless administrative process

Automation designed to free up administrative time and ensure no team celebration is missed.
