Business Intelligence over WhatsApp

Your numbers arrive on their own, on WhatsApp.

Brújula is a BI (Business Intelligence: turning sales data into information for decisions) system that works over WhatsApp. Every morning and afternoon, each rep gets where they stand: their sales, goal, progress and quotes to follow up. At the end of the day, the manager receives a summary of the whole team. Nobody has to log into a system.

In plain words

What is it and what is it for?

What is a KPI?

A KPI (Key Performance Indicator) is a number that tells you whether things are going well: today's sales, percentage of the goal, or quotes still waiting for follow-up.

The problem

The numbers live in the ERP (the sales and inventory system) and in reports someone builds by hand, screenshots and forwards. They arrive late, each in its own format, and a rep on the sales floor has no time to open a system.

The solution

Brújula queries the ERP at set times, builds each person's summary and sends it to their WhatsApp. The same data, in the same format, for everyone, every day.

Step by step

How a report arrives

Nobody requests or builds it: it runs on its own at the scheduled time.

Query

At the scheduled time it reads each rep's sales, goals and quotes from the ERP with read-only queries.

Build

It computes progress and comparisons, and renders the message or an image with each person's table.

Send

It delivers it through the official WhatsApp API (the interface for programs) to each rep, with only their own numbers.

Consolidate

At the end of the day, the manager receives the team summary: ranking, totals and trend.

Quotes to follow up

Each rep receives a table of their recent quotes —folio, customer, amount and next appointment date— as an image that reads well on a phone, so they know whom to call today.

Questions over chat

The idea evolved into an assistant that management can ask on WhatsApp "how are we doing this month?" and it answers with ERP figures, comparisons and the Excel or PDF on request. It only answers authorized numbers.

Under the hood

Simple outside, solid inside

Python and pandas

Python scripts read the ERP with SQLAlchemy and pyodbc (the SQL Server connector) and process data with pandas, a library for working with tables.

Read-only

ERP queries only read: Brújula never changes sales data.

Tables rendered as images

With matplotlib, each person's table is drawn as an image, with text wrapped to read well on a phone.

WhatsApp Cloud API

The image is uploaded to Meta's official API and sent to each rep's number. Outside the 24-hour window, approved templates are used.

Scheduled sends

An internal scheduler, or Windows Task Scheduler, triggers each send on time, every day.

Secure by design

Credentials and the WhatsApp token live in environment variables, outside the code. Each rep only receives their own data, based on the rep catalog.
