E-commerce

A complete online store, from catalog to checkout.

Vitrina is an online store (e-commerce) for a large hardware and building-supplies catalog: a home page with promotions, categories, instant search, product pages with reviews, a cart with discounts, a wishlist and checkout. Behind it sits its own API (the door the store uses to request data from the server), fed by the ERP (the business’s sales and inventory system) to show up-to-date prices and stock.

In plain words

What it is and why it matters

What is e-commerce?

A store on the internet: customers search, compare and buy from their phone or computer, at any time, without visiting the physical store.

The problem

A huge catalog is hard to browse, and if the price or stock online does not match what is in the store, customers lose trust.

The solution

Categories and a search box that find the product instantly, clear product pages with stock, and an ERP sync that keeps prices and inventory current without entering them twice.

Step by step

How a customer shops

Browse

Scroll the home page with banners and promotions, open the category menu or type in the search box.

Choose

The product page shows a photo gallery, discounted price, stock, tags such as Sale or New and reviews from other customers.

Fill the cart

Add products to the side cart, adjust quantities and see the total with discounts instantly. Anything for later goes to the wishlist.

Pay

At checkout (the online store’s cash register) the customer enters a shipping address and payment method, and the order is saved to their account.

Features

What the store does

Designed for customers who shop from their phone and for the team that manages the catalog.

Catalog and search

Categories and product groups with filters, a wide category menu and a search box that filters as you type.

Cart with discounts

Quantities, totals and discounts calculated instantly.

Visible stock

Every product shows whether it is available.

Product pages with reviews

Image gallery, star ratings, customer reviews and tags such as Bestseller, Sale, Premium, New or Eco.

Wishlist

Save products to buy later.

Customer accounts

Sign-up and sign-in to buy and check past orders.

Admin panel

Import products from a CSV file (a plain-text table exported from Excel) and edit the home page in blocks: banners, promotions and sections that can be added and reordered without code.

WhatsApp button

A shortcut so customers can ask questions before buying.

Search-engine ready

JSON-LD structured data (a description of the page that Google and other search engines understand) and social media tags.

How it is built

Its own frontend and API

A store connected to the business’s system, not a template.

React 19 and Vite 7

React interface organized into components and contexts (cart, products, wishlist), bundled with Vite. Images are optimized with sharp.

Express 5 API

A REST API (organized around resources such as products or orders) built with Express, with routes for accounts, products, orders, reviews, wishlist and sync.

SQL Server

Products, orders and accounts are stored in a SQL Server database.

ERP sync

A process copies categories, product groups, prices and stock from the ERP. It runs in the background so nobody waits, and logs every run.

Online payment

Checkout is integrated with Mercado Pago, the gateway that charges cards; it is switched on with each business’s credentials.

PWA

Installs from the browser. It caches the store’s files and checks the network first for the catalog, so it opens fast without showing stale prices.

Security

Protected in layers

JWT and bcrypt

Sessions use JWT (a signed token that proves who you are) and passwords are stored hashed with bcrypt.

Security headers

Helmet adds the HTTP headers that protect the browser from common attacks, such as embedding the store inside another page.

Attempt limits

Sign-in and sign-up accept a limited number of attempts per time window, to stop brute-force attacks (trying passwords one after another).

Allowed origins

CORS (the rule that decides which sites may call the API) only accepts the store’s domains.

Key-protected sync

Only someone holding the admin key can start an ERP sync.

Validated orders

The server checks every order: products with a valid quantity, a shipping address and a payment method.
