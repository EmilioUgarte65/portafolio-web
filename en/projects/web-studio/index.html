AI video editor

Video, audio and text on one timeline.

Web Studio is a video editor that runs on your computer and is used from the browser. Drag in your footage, music and logo, tell the AI what video you want, and it builds a multitrack timeline (several layers of video, audio and text) you can keep editing by hand. It exports to MP4 or to a Premiere Pro or DaVinci Resolve project.

In plain words

What it is and why it matters

An editor with an assistant

An editor in the style of CapCut or Premiere, with a media library, viewer, inspector and timeline, plus an AI assistant you chat with in plain language.

The problem

Turning an idea into a finished video means coordinating media, cuts, music, voices, subtitles and export. It is slow and repetitive, especially when making many similar videos.

The solution

An LLM (large language model, the kind of AI that understands and writes text) turns the request into an editing plan. The engine validates the plan, lays it on the timeline and renders it.

Step by step

How a video gets made

Upload your media

Drag footage, music and a logo into the project library.

Chat with the AI

Describe the video. The AI asks who it is for, the format and the length, and suggests ideas to pick from.

Fine-tune by hand

Cut, duplicate and move clips on the timeline; adjust each one in the inspector, in simple or advanced mode.

Export

Render an MP4 or a Premiere or DaVinci project. Before delivery, a built-in critic reviews the result.

Features

A complete video studio

Every change is an operation the server validates and saves with history and versions.

Multitrack editor

Media library, program monitor with smooth playback, inspector and a multitrack timeline. Every edit lands in a history with restorable versions, and the interface never exposes internal data.

Voices and subtitles

Local or cloud synthetic voices, microphone voice clean-up and automatic subtitles from the transcription.

Made-to-measure music

If you don't upload a track, it composes original music fitted to the video's cuts.

Built-in critic

Before showing a video, it renders a preview, measures loudness, first frame and length, asks the AI for a visual critique and applies the fixes as patches to the plan, for up to two rounds.

Promos from a link

Paste a web app's link: it captures the app with an automated browser, picks up its logo, colors and fonts, and builds the promo.

Professional export

Projects for Premiere Pro, DaVinci Resolve or OTIO (OpenTimelineIO, an open timeline format), as well as MP4.

Under the hood

How it is built

Python and FastAPI

A local Python server built with FastAPI exposes an API (the interface programs use to talk to each other). The interface is a local web page in HTML, CSS and JavaScript.

Validated JSON plans

The AI never edits the video directly: it writes a plan in JSON (a text data format) that is validated against a schema before it touches the timeline.

FFmpeg as the render engine

Rendering runs on FFmpeg, with GPU (graphics card) encoding when available; without a GPU everything runs on the CPU.

Swappable AI

The "brain" can be Claude Code or Codex, with OpenAI as an option. No part of the editor depends on a single provider.

Local AI models

Voice separation, transcription and face detection run on the computer itself; the models download automatically the first time.

Verified export

Exported projects are rebuilt and compared with the engine's render using PSNR (a measure of how similar two images are). Service keys are stored encrypted per user.
