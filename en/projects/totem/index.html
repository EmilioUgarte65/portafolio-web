Digital signage

Screens that change with the weather and from your phone.

Totem is a digital signage system for an advertising totem. A desktop app pops up at scheduled times, plays a video matched to the current weather with live conditions on top, and closes on its own. Text, schedules and videos are managed remotely from a web panel and a mobile app. In the demo, actions change in-memory sample data and do not control real screens.

In plain words

What it is and why it matters

A scheduled on-screen spot

At set times, the totem interrupts its regular content with a video tied to the real weather, the temperature and a promotional message. When it ends, the screen goes back to what it was showing.

The problem

The screens looped the same fixed videos, and changing a message or a video meant walking up to the totem's computer.

The solution

Videos per weather condition, plus text and schedules edited from a phone. The totem listens for changes in real time and downloads only what is new.

Step by step

A day with Totem

Open the panel

From the web or a phone; only authorized emails can sign in.

Write the message

A short text with its color, for today or for a specific date.

Schedule and upload

Pick fixed times or intervals and upload a video for each kind of weather.

The totem does the rest

Minutes before, it checks the weather; right on time it shows the video with the message and closes when done.

Features

Live content without touching the screen

Everything changed in the panel reaches the totem in real time.

A video for every forecast

It queries a weather data service and picks the video by condition: clear day or night, cloudy, rain, storm or fog. The feels-like temperature uses Steadman's apparent temperature formula.

Live streams

Puts a Facebook live stream on the totem in full screen, for a set time and without the social network's interface.

Emergency switch

A kill switch isolates the totem: it stops listening to the cloud, hides the text and keeps playing local videos and the weather.

Web panel and mobile app

A dashboard with a live totem preview, text, schedules, weather videos, cities and an activity log. The web panel is a PWA (an app you install from the browser) and there is a native mobile app.

Activity log

Every action is recorded with who and when; entries can be created but never edited or deleted.

Forced sync

Admins can tell the totem to fetch new videos right away.

Under the hood

How it is built

Electron on Windows

A desktop app in Electron (desktop software built with web technology) that lives in the system tray, with a Windows installer and a setup wizard.

Firebase, no server of its own

Authentication, a Firestore database with real-time listeners and video storage on Firebase. There is no local server: all state flows through the cloud.

Two-barrier downloads

A video is only fetched when its version changes, at most once a day per slot. It downloads to a temp file and is renamed at the end, so a video is never left half-written.

Weather with four fallbacks

Primary city, backup city, local cache and default values: the screen never runs out of weather data.

Two screens, pixel-exact

Borderless windows side by side with proportional sizing; the weather card has horizontal and vertical layouts. The window and the main process talk over an isolated IPC (inter-process communication) bridge.

React and React Native

Panel in React 18 with Vite and Tailwind; mobile app in React Native with Expo. Firestore rules with an allowlist of emails and field validation.
