In plain words

What it is and why it matters

What is NL-to-SQL?

Natural Language to SQL: translating a plain-language question ("how much did we sell this month?") into SQL, the language used to query databases. It's done by an LLM (large language model) that knows the structure of the tables.

The problem

A company's information lives in its ERP (the sales, inventory and accounting system), and every new report needs someone who knows SQL and dozens of tables. Questions wait days for someone to build the query.

The solution

Anyone asks in their own words. The AI writes the query, the server checks that it only reads data and runs it, and the AI reads the results back to explain them with concrete figures, charts and a table.

Step by step

How it answers a question

A two-pass flow: the AI first builds the query, then explains the real data.

Ask

By text or by voice. Dictation uses the browser's speech recognition and, when that's not available, Whisper on the server, with a filter that discards phrases Whisper invents during silence, like "thanks for watching".

First pass

The LLM answers in fixed sections: the SQL query, the chart configuration and, when needed, the parameters of an accounting query.

Safe execution

The server wraps the query inside a consolidated sales view (a CTE: a named query that can be reused), only allows SELECT and WITH, and applies a timeout and caching.

Second pass

The real rows go back to the LLM, which writes the narrative with figures, comparisons and findings (data storytelling), and a neural voice reads it aloud.

What it does

From a question to a decision

All your business intelligence, just a conversation away.

Ask in natural language

Type or speak the way you would to a colleague: "how are sales going?", "compare this quarter with last quarter". Lumen understands the intent and keeps track of the conversation.

Translates to the query

It turns your question into the right query and runs it against your data, without you needing any technical knowledge.

Narrates the result

It doesn't just show a table: it explains what happened and what stands out, like an analyst summarizing the report for you.

Financial statements

Balance sheet, income statement, trial balance, chart of accounts and cash flow, with period filters and period-over-period comparison.

Interactive dashboards

Key indicators, bar, line or pie charts, and tables you can sort with a click on any column.

Export to Excel and PowerPoint

Take any report into a formatted Excel sheet or a presentation with a title slide, indicators, charts and narrative.

By voice too

Ask your question out loud and hear the answer: perfect for when you're on the move.

Under the hood

How it's built

Node.js, Express and Vite

A Node.js 20 server with Express 5; a JavaScript-module frontend bundled with Vite, with charts in Chart.js. It installs as a PWA (an app from the browser).

Read-only connection to the ERP

It reads a Microsoft Dynamics 365 Business Central ERP on SQL Server. A validator only lets SELECT and WITH through and blocks any command that writes or deletes.

The AI key stays on the server

The browser never talks to the AI provider directly: the server builds the instructions with the data schema and keeps the API key.

Layered security

Sessions with JWT (a signed token that expires), passwords hashed with bcrypt, secure headers with Helmet, request rate limits and validation of every input with Zod.

Fast and observable

Query caching with Redis, a timeout per query, compression, logging with Pino and errors reported to Sentry.

Tested and containerized

Vitest tests for the SQL validator, the AI response parser and the voice filter; deployment with Docker.
