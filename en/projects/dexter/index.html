In plain words

What it is and why it matters

What is an AI agent?

An LLM (large language model, the AI that understands and writes text) with tools: it can read files, run commands and edit code, step by step, until a task is done. Think of an assistant that doesn't just answer but acts.

The problem

Every session starts from scratch: the agent forgets decisions, conventions and bugs it already solved. Each tool is configured differently, and wiring in WhatsApp, a smart home or a security review has to be done piece by piece.

The solution

A "base brain" injected into each agent's configuration: a lightweight capability index, skills loaded on demand, memory across sessions, and an auditor that reviews any external code before it runs.

Step by step

How it works

Install it once; after that it grows with every session.

Install

An installer in Bash, PowerShell or a terminal UI detects which agent you use and backs up your current setup before touching anything.

Inject

It adds the base instructions and capability index, copies the skills, and configures MCP servers, hooks (automatic actions on agent events) and permissions.

Load on demand

Each skill bundle activates only when the conversation mentions its trigger keywords; only the index stays in context, so fewer tokens are spent.

Remember and grow

It saves decisions, bugs and discoveries to memory. If a skill is missing, it writes one, audits it and activates it without a restart.

What's included

An agent with superpowers, ready in minutes

Memory, automation, communications, and the ability to create its own skills. All inside the agent you already use.

Persistent memory

It remembers decisions, findings and conventions across sessions (Engram, on SQLite). Stop re-explaining the context to your agent every time.

46+ on-demand skills

Skills that load only when needed, fast and without flooding the context. From development to security.

WhatsApp auto-responder

Works with a regular number, no business account needed. Unknown contacts get answers from your "persona" in your style and rules, and voice notes get transcribed.

Home automation

Control Philips Hue, Home Assistant and devices over MQTT (a lightweight messaging protocol for IoT) straight from your agent.

Model router

Checks which AI providers are responding (Anthropic, OpenAI, Google or local models with Ollama), picks the fastest and falls back to another if one fails.

Security auditor

Before running an external or generated skill, it scans for data sent to outside servers, eval/exec, obfuscated code and prompt injection. It answers PASS, WARN or BLOCK.

SDD workflow

Spec-Driven Development: for big changes, first a proposal, spec, design and tasks; then implement and verify against the spec.

Notifications and webhooks

Sends each session's summary to Telegram, WhatsApp, Slack or Discord, and receives webhooks (HTTP callbacks from other services) to trigger actions.

Desktop automation + 112 ready-made flows

Describe a task in natural language and Dexter takes screenshots, reasons about the screen, and runs clicks and keystrokes until it's done, saving the sequence as a reusable macro. Plus over 112 community flows (ClawFlows) ready to import.

Self-extending, with a marketplace

Need a new skill? Describe it and Dexter writes it, runs it through the auditor and activates it instantly, without a restart. It can also search and install community skills from its own marketplace.

Under the hood

How it's built

Multi-agent

Claude Code, OpenCode, Codex, Cursor, Gemini CLI and VS Code: one ecosystem across all of them.

One strategy per agent

Each agent stores its configuration differently, so the installer merges JSON, replaces files, writes TOML or appends as needed, always backing up first.

MCP (Model Context Protocol)

An open standard for connecting tools and data to an agent. Dexter configures the Engram memory and Context7 (up-to-date library docs) as MCP servers.

Local memory (Engram)

SQLite with FTS5, SQLite's full-text search. It saves and retrieves context across sessions, on your machine.

Python, Node.js and Go

Skills in Markdown with Python scripts; WhatsApp and Telegram servers in Node.js (WhatsApp through the Baileys library); a visual installer in Go with Bubbletea.

Open source and tested

Open source under Apache 2.0, in active development, with pytest tests for the scripts and bats tests for the installer.
